แผนที่ประเทศไทย: สถานศึกษาและเด็กพิการ 77 จังหวัด

ข้อมูล ณ 10 มิถุนายน 2569 · รายละเอียดและจำนวนนักเรียนเปลี่ยนตามประเภทสถานศึกษาที่เลือก · เพิ่มชั้นรายชื่อ สพม. จากระบบ SET (แยกจากยอดปี 2569)
① เลือกข้อมูลที่ต้องการแสดง
เลือกประเภทสถานศึกษาเพื่อดูพื้นที่ครอบคลุม
กำลังโหลดขอบเขตจังหวัด…
บนมือถือ: แตะจังหวัดเพื่อดูรายละเอียด · ใช้สองนิ้วซูม · ซูมระดับ 8 ขึ้นไปเพื่อดูชื่อจังหวัด

รายชื่อจังหวัด

เลือกจังหวัดบนแผนที่หรือในรายชื่อ เพื่อดูข้อมูลตามหัวข้อที่เลือก
แหล่งข้อมูล: รายงานสถานศึกษารายจังหวัด 77 จังหวัด (รวมข้อมูลเด็กแยกประเภทสถานศึกษาจากตารางรายจังหวัด) และตารางรายชื่อสถานศึกษาที่รวบรวมจากเอกสารต้นทาง; ขอบเขตจังหวัด: OpenGISData-Thailand (GitHub). ความครอบคลุมหมายถึงจังหวัดที่มีสถานศึกษาตั้งอยู่ ไม่ใช่เขตบริการหรือภูมิลำเนานักเรียน. ยอดรวมระดับประเทศปี 2569 ครบ 5 ประเภท (รวม สพม. 1,305 แห่ง) แต่ยอดที่ระบายสีและรายละเอียดรายจังหวัดยังเป็น 4 ประเภท เนื่องจากยังไม่มีข้อมูล สพม. ปี 2569 แยกจังหวัด; ชั้นรายชื่อ สพม. จาก SET แสดงแยกต่างหาก และมี 8 โรงเรียนที่ยังไม่สามารถระบุจังหวัดได้. เว็บไซต์ต้องใช้อินเทอร์เน็ตเพื่อโหลดแผนที่.

หมายเหตุ: สพม. จาก SET มี 2,361 รายชื่อ; จัดจังหวัดได้ 2353 รายชื่อ; ยังไม่สามารถระบุจังหวัดได้ 8 รายชื่อ. ข้อมูลนี้ไม่ใช่ยอดโรงเรียนเรียนรวม สพม. 1,305 แห่ง ปี 2569 · ดูรายชื่อ 8 โรงเรียนที่ไม่สามารถระบุจังหวัดได้

โรงเรียน สพม. ที่ไม่สามารถระบุจังหวัดจากข้อมูล SET ได้ (8 แห่ง)

ระบบ SET ระบุที่อยู่ของโรงเรียนเหล่านี้ไม่ครบ และเขตพื้นที่การศึกษาครอบคลุมมากกว่าหนึ่งจังหวัด จึงยังไม่จัดลงจังหวัดใดในแผนที่ เพื่อไม่ให้ยอดรายจังหวัดคลาดเคลื่อน
